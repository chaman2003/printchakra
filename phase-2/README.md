# PrintChakra Phase 2 Info Page

This directory contains a standalone information page for the PrintChakra Phase 2 project.

## Deployment to Vercel

To deploy this page to Vercel, you can:

1. **Vercel CLI**:
   ```bash
   cd phase-2
   vercel deploy --prod
   ```

2. **GitHub/GitLab/Bitbucket**:
   - Push your project to a repository.
   - Connect the repository to Vercel.
   - Set the **Root Directory** to `phase-2` in the Vercel project settings.

## Contents
- `index.html`: The main project information page.
- `vercel.json`: Deployment configuration for Vercel.
- Project documents (PDFs, PPTX, Images) linked within the page.
